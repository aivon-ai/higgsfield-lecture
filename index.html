Part 03 · Setup

클로드와 힉스필드 연결하기

강의에서 안내한 흐름 그대로 다섯 단계로 정리했습니다.
1

클로드 접속

구글 검색에서 클로드를 찾은 뒤 구글 계정으로 로그인합니다.

2

사용자 지정

좌측의 사용자 지정 버튼을 클릭합니다.

3

커넥터 추가

커넥터 → 플러스 버튼 → 커스텀 커넥터 추가 순서로 진행합니다.

4

이름과 서버 URL

이름과 서버 URL 입력란을 확인합니다.

5

힉스필드 MCP 주소 입력

이름은 “힉스필드”로 적고, 원격 MCP 서버 URL에는 힉스필드의 MCP 주소를 복사해 넣습니다.

다른 방법: 힉스필드의 MCP 메뉴에서 Claude를 선택하면 연결 안내를 따라갈 수 있습니다.
Check

연결 확인하기

새 채팅에서 아래 문장으로 사용 가능한 이미지·비디오 도구를 확인합니다.
힉스필드 커넥터로 어떤 이미지와 비디오 도구들을 사용할 수 있는지 확인해봐
Practice 01

10초 드라마 장면 만들기

세 명의 인물 이미지를 만든 뒤, 스토리보드와 10초 영상 생성까지 이어갑니다.
STEP 1 · 인물 이미지

50대 한국 여성, 20대 한국 여성, 20대 한국 남성 / 나노바나나 2

STEP 2 · 스토리보드

한국어 대사와 액션을 포함한 10초짜리 막장 드라마 씬

STEP 3 · 영상

앞서 생성한 세 인물을 레퍼런스로 / 480p / 9:16

“50대 한국 여성과 20대 한국 여성, 그리고 20대 한국 남성의 이미지를 힉스필드 MCP의 나노바나나 2 모델을 활용해서 각각 생성해줘. 포토리얼리스틱한 느낌을 잘 살려서”
“한국의 막장 드라마 장면을 만들어볼거야.

한국어 대사와 액션을 포함한 10초짜리 씬의 스토리보드를 텍스트로 제작해줘.

다양한 샷으로 나누어서”
“해당스토리로 10초자리 드라마 한 장면을 제작해줘.
앞에 생성한 세 인물을 레퍼런스로 영상을 만들어.
힉스필드에서 제작 가능한 영상 모델을 활용해서 480p 화질로 9:16 화면 비율로 부탁해.”
팁: 꼭 한 창에서만 작업할 필요는 없습니다. 클로드 창을 여러 개 열어 각각 다른 작업을 진행해도 됩니다.
Practice 02

10초 광고 영상 만들기

“노원 AI 크루” 포도맛 탄산음료 이미지를 만든 뒤, 빠른 씬 전환과 청량함을 강조한 광고 영상으로 이어갑니다.
STEP 1 · 제품 이미지

“노원 AI 크루” 포도맛 탄산음료 / GPT Image 2.0

STEP 2 · 광고 스토리보드

10초 / 빠른 씬 전환 / 청량함 강조

STEP 3 · 광고 영상

제품 이미지를 레퍼런스로 / 16:9

“노원 AI 크루”라는 포도맛 탄산음료 이미지를 하나 생성해줘. 힉스필드 MCP의 GPT Image 2.0 모델을 활용해서
“해당 음료수 이미지로 10초짜리 광고를 제작하려고 해. 빠르게 씬이 넘어가면서 청량함을 강조한 스토리보드를 텍스트로 제작해줘.”
“해당 스토리를 바탕으로 10초짜리 광고를 제작해줘.
생성해준 음료 제품을 레퍼런스로 영상을 만들어.
힉스필드에서 제작 가능한 영상 모델을 활용해서 16:9 비율로 제작해줘.”
